#EEG-Based Emotion Recognition Using Genetic Algorithm Optimized Ensemble Model

#This repository contains the implementation and research work for EEG-based emotion recognition using Genetic Algorithm optimized ensemble learning techniques.

## Overview
The project focuses on real-time emotion recognition using EEG signals from the DEAP dataset. The proposed system combines advanced preprocessing, feature extraction, feature selection, and deep learning models to improve classification accuracy.

## Key Features
- EEG signal preprocessing using ICA and bandpass filtering
- Data augmentation using Gaussian Noise Injection and Time Wrapping
- Feature extraction using:
  - Empirical Mode Decomposition (EMD)
  - Wavelet Transform (WT)
- Feature selection using Genetic Algorithm (GA)
- Deep learning models:
  - CNN
  - LSTM
  - RNN
- Ensemble voting classifier

## Dataset
- DEAP Dataset
- 5 emotion classes:
  - Happy
  - Sad
  - Angry
  - Confused
  - Surprise
